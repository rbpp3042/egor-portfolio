01CRM и продажи

Подготовить клиентскую базу к повторным продажам

Собрал данные amoCRM примерно по 23 500 сделкам и 11 500 контактам. Объединил записи до уровня человека с телефоном, подготовил сегменты и файл для СМС-рассылки.

При проверке обнаружил, что выгрузка только по дате создания пропускает значительную часть нужных сделок.

Результат этапа — подготовленная база и сегменты. Эффект рассылки в выручке пока не измерен.

amoCRM · API · обработка данных
02Рекламное агентство

Автоматизировать отчётность рекламного агентства

Для рекламного агентства разработал пайплайн: данные из Google Sheets и Drive → обработка и хранение в PostgreSQL → Excel-отчёты и Google Docs → доставка через Telegram.

Добавил проверку по эталонным отчётам. Обработку, экспорт и доставку разделил, чтобы новый формат отчёта не требовал переделки всей системы.

Python · PostgreSQL · Google API · Telegram Bot API
03AI-помощник

Подготовить врачу сводку по фотографиям пациента

Разработал систему для ортодонтической клиники: классификация снимков, выделение признаков и сводка через Telegram.

Настроил многоэтапную обработку с LLM, проверку качества на размеченных снимках и журналирование вызовов. Медицинское решение остаётся за врачом.

Python · LLM API · анализ изображений · оценка качества
04Платежи и доставка

Связать эквайринг, CRM и кассу

Настроил связку платёжной системы, CRM и кассы, а также уведомления менеджерам о статусе оплаты и сообщения клиентам о доставке через мессенджеры.

Автоматизация охватывает и платёжную операцию, и передачу информации тем, кому она нужна: менеджеру и клиенту.

Эквайринг · CRM · касса · мессенджеры

Настроить автоматические реактивационные рассылки

Email · мессенджеры · реактивация клиентов

Находить инфоповоды для коммуникаций в реальном времени

Для WTF настроил мониторинг Telegram-каналов и отбор сигналов для real-time marketing communications.

Задача — выделять в потоке публикаций события и темы, на которые команда может оперативно отреагировать в маркетинговых коммуникациях.
